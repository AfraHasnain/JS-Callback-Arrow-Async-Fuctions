Arrow Function

Q1. Create a calculator using arrow functions for addition, subtraction, multiplication, and division.

const add = (a, b) => a + b; const subtract = (a, b) => a - b; const multiply = (a, b) => a * b; const divide = (a, b) => a / b; console.log("Addition: " + add(550, 680)); console.log("Subtraction: " + subtract(590, 760)); console.log("Multiplication: " + multiply(50, 8)); console.log("Division: " + divide(8, 1200));

Callback Function

Q2. Create a function that accepts an arrow function as a callback and displays the result of multiplying two numbers.

function DisplayResult(a, b, callback) { let result = callback(a, b); console.log("Callback Result: " + result); } DisplayResult(9, 7, (x, y) => x * y);

Async Function

Q3. Create an async function that waits 3 seconds and then prints "Data Loaded Successfully".

async function LoadData() { console.log("Loading Data..."); await new Promise((resolve) => setTimeout(resolve, 3000)); console.log("Data Loaded Successfully"); } LoadData();

Callback Function | Arrow Function

Q4. Create a function that checks a student's marks using a callback:
- Marks 40 or above: Passed.
- Marks below 40: Failed.

function CheckMarks(marks, callback) { let result = callback(marks); console.log("Check Student Marks: " + marks + " " + result); } CheckMarks(73, (m) => (m >= 40 ? "Passed" : "Failed")); CheckMarks(32, (m) => (m >= 40 ? "Passed" : "Failed"));
